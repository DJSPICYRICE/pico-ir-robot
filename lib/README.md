# Libraries

Copy these MicroPython libraries onto the Pico (into `/lib` or the root):

| Library | Used for | Source |
|---|---|---|
| `ir_rx/` (`__init__.py`, `nec.py`) | NEC IR remote decoding | [peterhinch/micropython_ir](https://github.com/peterhinch/micropython_ir) |
| `hcsr04.py` | HC-SR04 ultrasonic sensor | [rsc1975/micropython-hcsr04](https://github.com/rsc1975/micropython-hcsr04) |

They aren't included here; get them from the original repos so their licenses stay with them.
